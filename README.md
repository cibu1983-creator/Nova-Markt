# NOVA Markt

Mobile-first Marktplatz-Testversion mit Supabase-Backend.

## Funktionen
- Registrierung und Login
- Profile
- Anzeigen mit bis zu 5 Bildern
- Suche, Kategorien und Sortierung
- Favoriten
- Nachrichten
- Anzeigen melden
- PWA-Grundlage für Android
- Rechtliche Platzhalter / Plattformhinweis

## Testbetrieb
Die Anwendung ist für GitHub Pages vorbereitet. Vor einem öffentlichen Produktivstart müssen insbesondere Impressum, Datenschutz, Kontakt-/Meldestelle und weitere rechtliche Angaben mit echten Betreiberangaben vervollständigt und geprüft werden.
